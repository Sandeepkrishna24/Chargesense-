Build a full-stack, mobile-first EV Charging Recommendation System called “ChargeSense” for the Indian EV ecosystem.

This application must run completely inside a Replit workspace.

────────────────────────────
ChargeSense provides **intelligent charging station recommendations** based on:
- User’s current location
- User-specified vehicle range
- Charger type & connector compatibility
- Queue waiting time

The UI must exactly follow **Ather’s clean, minimal, confident design language**.

────────────────────────────
BATTERY STATUS, RANGE & LOCATION (CRITICAL)
────────────────────────────
This screen is used to drive ALL recommendations.

Inputs:
- Battery percentage (slider)
- User-specified usable range (in KM)
- Current location:
  - Manual input
  - OR use current GPS location

IMPORTANT:
The range entered by the user is the **maximum search radius** for charging stations.

Example:
If user enters 30 KM, only charging stations within a 30 KM radius from the user’s CURRENT LOCATION must be considered.

────────────────────────────
DISTANCE CALCULATION (MANDATORY)
────────────────────────────
- Use the Haversine formula
- Calculate distance between:
  - User’s current latitude & longitude
  - Charging station latitude & longitude

Example:
User location: Guindy
Station distance shown as:
- “3.5 km away”
- “5 km away”

This distance must be:
- Computed automatically
- Displayed clearly on each station card

────────────────────────────
CHARGING STATION FILTERING (STRICT RULES)
────────────────────────────

A charging station MUST be shown ONLY IF:

1. The station is WITHIN the user-specified range radius
   (e.g., 20 KM → only stations ≤ 20 KM)

2. The station’s charger type matches the vehicle
   (AC / DC compatibility)

3. The station’s connector type matches the vehicle connector

Stations failing ANY of the above conditions must NOT be shown.

────────────────────────────
QUEUE & WAITING TIME INTELLIGENCE
────────────────────────────
- Subscribe to realtime queue_entries from Supabase

Charging time calculation:
((targetSOC - currentSOC) / 100 × battery_capacity_kwh) / charger_power_kw × 60

Queue waiting time:
- Sum of charging times of all vehicles ahead in queue

Display clearly:
- Distance from user
- Charging time
- Queue waiting time
- Total time
- Estimated cost
- Availability indicator (🟢 / 🟡 / 🔴)

────────────────────────────
RECOMMENDATION ENGINE
────────────────────────────
Rank charging stations ONLY AFTER filtering by:
- Range radius

- Connector compatibility

Ranking factors:
- Distance from user

- Reliability score

UI:
- Highlight TOP 3 recommended stations
- Explain WHY each station is recommended
- Use swipeable cards (Ather-style, no tables)
